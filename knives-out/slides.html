THE CONCEPT

One target. One code. No warning.

Every player is assigned a target in secret. Kills are confirmed in person with a one-time code. The game runs continuously in the background of everyone's real day — until one name is left standing.

  • Dual interface — a player app for the hunt, a moderator console for running the round
  • Firebase Realtime Database keeps every phone in sync to the second
  • Built module-by-module: auth, chain, immunity, ghosts, elimination, analytics

MODULE 03

Confirm the kill.

No self-reporting. A kill only counts once both sides confirm it, in person, with a code that expires fast.

  • Killer generates a 6-digit code, shows it to the target
  • Victim enters that code to confirm — code expires after 10 minutes
  • House rules baked into the flow: no kills mid-meeting, no eyewitnesses, standing targets only on the office floor
  • Dead players can't generate codes; ghosts generate codes against their ghost assignment
